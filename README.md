### Dataset Details

<details>
<summary><b>heart.csv</b> — Heart Disease Prediction</summary>

<br>

A multivariate dataset commonly used for binary classification tasks. It contains clinical and demographic attributes of patients, with the target variable indicating the presence or absence of heart disease.

**Features include:** `age`, `sex`, `cp` (chest pain type), `trestbps` (resting blood pressure), `chol` (cholesterol), `fbs` (fasting blood sugar), `restecg`, `thalach` (max heart rate), `exang` (exercise-induced angina), `oldpeak`, `slope`, `ca`, `thal`, `target`

</details>
